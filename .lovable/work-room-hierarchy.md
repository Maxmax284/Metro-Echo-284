# Work room hierarchy

## Grouping rationale

Everything in Work used to sit at one weight, so a daily lane looked exactly like an advanced tool. The grouping is presentation only — every destination is the same surface it always was, no routes changed.

```text
Recent projects      the jobs Vanta is tracking
Desks
  Daily work         Inbox · Commitments · Actions
  Knowledge          Briefs · Documents · Memory
Deeper tools         Schedule · Sherlock · Awareness · Cockpit
```

## Recent projects

Four most recent, status rail on the left carrying the colour, mono time label, chevron. Tapping travels into the project.

## Desks

The word stays. Helper line: "Desks hold the different kinds of work Vanta tracks." Daily work is the three lanes touched every day; Knowledge is what Vanta has read, written, and remembered.

## Deeper tools

Dashed panel, slightly quieter, its own one-line note. Cockpit lives here labelled "Advanced dense view" rather than promoted as a peer of Inbox. Not removed — de-emphasised until usage says it is redundant.

## Mobile

Two-column desk grid at 384px, 44px minimum tap targets, no horizontal overflow, section notes collapse after three visits so the room shortens as the user gets familiar.
