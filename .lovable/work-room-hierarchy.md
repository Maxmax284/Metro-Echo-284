# Work room hierarchy

Superseded by `.lovable/vanta-work-front-page.md`. Work no longer opens as a directory.

```text
Where things stand   briefing: Start here + Needs you / Arrived / Due / Drifting
Recent projects      the jobs Vanta is tracking
Where work lands     Projects · Inbox · Commitments · Actions · Briefs · Documents · Schedule
Where Vanta looks    Memory · Sherlock · Awareness · Cockpit
```

The old Daily work / Knowledge / Deeper tools split is gone: it grouped by touch frequency, which the user had to learn. The two shelves group by mental model instead — things that arrive and get worked, versus places Vanta reads on your behalf. Routes, counts and desk peeks are unchanged.

## Mobile

Two-column desk grid at 384px, 44px minimum tap targets, no horizontal overflow. The briefing shows two rows per lane with the true total beside the lane name, so the room stays short.
